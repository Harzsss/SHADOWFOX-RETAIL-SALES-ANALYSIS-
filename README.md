# Retail-Sales-Analysis
Retail Sales and Customer Behavior Analysis using Python

Project Description

This project analyzes retail sales data using Python to understand sales performance, profit, product categories, and regional sales.

Objective

- Analyze overall sales and profit.
- Identify top-performing product categories.
- Understand region-wise sales performance.
- Find useful business insights from the dataset.

Dataset

- Dataset: Sample Superstore
- Records: 9,994
- Columns: 21
- Format: CSV

Tools Used

- Python
- Pandas
- Matplotlib

Analysis Performed

- Data loading and preprocessing
- Missing value and duplicate checking
- Sales and profit analysis
- Category-wise sales and profit analysis
- Region-wise sales visualization

Key Findings

- Technology has the highest sales and profit.
- Furniture has high sales but comparatively low profit.
- Office Supplies generates good profit despite lower sales.

Project Files

- "Sample - Superstore.csv" – Dataset
- "sales_analysis.py" – Python analysis code

Conclusion

This project helps understand retail sales performance and provides useful insights for business decision-making.
